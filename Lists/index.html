Lists: Unordered and Ordered

Unordered Lists Look like This:
  • Item 1
  • Item 2
  • Item 3

Notice that they have bullet points!

An Ordered List Looks Like This:
  1. Item 1
  2. Item 2
  3. Item 3!

Notice that these items have numbers!

Unordered Lists are created using the "ul" tag. Ordered Lists are created using "ol" instead.

The items inside a list (Unordered or Ordered) are created using the "li" tag.
